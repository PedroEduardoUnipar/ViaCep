# ViaCEP

Projeto acadêmico em Java para consulta de endereços a partir de um CEP utilizando a API pública ViaCEP.

## Tecnologias

- Java
- Maven
- API ViaCEP
- Lombok

## Estrutura

- `src/main/java/br/unipar/backend/Main.java` — consulta o CEP informado pelo usuário
- `src/main/java/br/unipar/backend/model/Endereco.java` — modelo dos dados de endereço
- `pom.xml` — configuração Maven

## Objetivo

Praticar consumo de API HTTP, leitura de resposta, modelagem de classes e organização de um projeto Maven.

## Origem

Este projeto foi separado de um repositório maior de exercícios de back-end para ficar disponível de forma independente e organizada.
